# Codex 个人数字资产

整理可复用的工作规范与个人技能，保留具体流程及验证方法。公开内容不包含个人材料、聊天记录、账户配置或访问凭据。

## 内容

| 资产 | 用途 |
|---|---|
| [AGENTS.md](AGENTS.md) | 沟通、任务范围、授权与质量约定的脱敏版本 |
| [课程作业交付与验收](skills/hhy-coursework-delivery/SKILL.md) | 按当前要求组织课程成果、真实证据和最终提交包 |
| [Windows存储维护](skills/hhy-windows-storage/SKILL.md) | 按批准范围盘点、清理、迁移并验证保存位置 |
| [只读迁移核验工具](skills/hhy-windows-storage/scripts/verify_migration.py) | 文件清单、SHA256、空目录及源变化核对；不复制或删除数据 |

目前只维护这两个个人技能。现有专业文档、Notebook、绘图等技能仍承担对应能力，个人技能提供适用范围和验收流程。

## 使用

按当前Codex支持的本地技能目录安装对应文件夹，并可显式调用 `$hhy-coursework-delivery` 或 `$hhy-windows-storage`。安装前检查已有同名目录，避免覆盖自定义内容；具体全局目录以当前客户端文档为准。

`AGENTS.md`可作为工作约定参考，不建议直接覆盖已有全局配置。迁移工具依赖Python 3.10及以上的标准库；在仓库根目录运行 `python -m unittest discover -s tests -v` 检查工具。

## 验证与边界

迁移工具的16项自动测试已通过，覆盖内容损坏、源文件变化、空目录、路径越界、链接风险和禁止覆盖等场景。两个技能还完成了12组、共24次独立上下文对照运行，所测任务的必要结果与原件保留检查均通过；Notebook结果另用全新内核运行核对，报告PDF经过页面查看。

这轮对照中没有发现所测验收项退步。真实应用数据库迁移、不同软件版本及长期使用效果仍按具体任务验证；测试不承诺所有任务都更快或更好。工具生成的清单/报告可能包含本机路径，不提交到公开仓库。

仓库只包含新编写的个人流程和工具，没有复制第三方技能包。尚未指定开源许可证；第三方工具自身的授权条款不因本仓库而改变。

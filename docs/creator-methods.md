# 公开方法的吸收与取舍

核对日期：2026-10-16。这份记录区分方法采用和运行代码移植：本轮读取作者公开仓库的选定文件，没有运行上游脚本或安装整套工具。表中的做法按本仓库场景重写，完整上游署名和许可保存在相关技能的references目录。

## 已采用

- [花叔结构化调研](https://github.com/alchaincyf/huashu-skills/blob/fdb4086348cebda0ec9cf81cdcb546cc18ff3020/huashu-research/SKILL.md)：重要发现带来源、日期与阶段记录，便于续接；只读调查不自动写知识库或记忆。
- [卡兹克横纵分析](https://github.com/KKKKhazix/khazix-skills/blob/322346ded8129436b3f64707789a73e732ae24d9/hv-analysis/SKILL.md)：需要时追关键版本变化，并与同条件的现有替代比较；不强制完整传记、长篇PDF或固定字数。
- [卡兹克任务书](https://github.com/KKKKhazix/khazix-skills/blob/322346ded8129436b3f64707789a73e732ae24d9/leader/SKILL.md)：目标、约束、建议分开；采用判断落实到实际结果，不固化作者的字符上限或代用户批准。
- [花叔个人素材](https://github.com/alchaincyf/huashu-skills/blob/fdb4086348cebda0ec9cf81cdcb546cc18ff3020/huashu-material-search/SKILL.md)：从真实材料提取可复用观点；不借用作者经历，不把一句评价扩写成没有依据的时长或数字。
- [花叔女娲](https://github.com/alchaincyf/nuwa-skill/blob/7fa1f60cfe3cf495e38c93626f239e06ecc2ee8e/SKILL.md)：提取如何判断及其适用条件；不模仿名人人格，不批量下载著作或新建人物代理。
- [花叔Excel](https://github.com/alchaincyf/huashu-excel/blob/5b8831257eeac8ce84d3c63c3c969dadaab15981/SKILL.md)：原表体检、文本编号、空白与0、合计与明细、原始定位、独立核数；融入课程验收，不另装工具链。
- [花叔演讲教练](https://github.com/alchaincyf/huashu-skills/blob/fdb4086348cebda0ec9cf81cdcb546cc18ff3020/huashu-speech-coach/SKILL.md)：从听众问题组织证据，讲稿补解释，内容与图表一起交接；老师模板、格式及实际时长优先。

## 本轮不采用

- 花叔Design：真实资产与视觉检查有用，但已有专门设计能力；不再新增重叠设计入口，不强制每次三稿等待选择，也不用HTML或整页图片替代要求可编辑的PPTX。
- 花叔文章编辑：分批保存值得保留，但现有流程已有；不重复加入每3—5项报进度、每次编辑重新确认的机制。
- 花叔信息检索：不采用媒体高于官方、固定旧年份和半年失效阈值。
- 卡兹克写作：不把作者口头禅、经历、模型偏好变成使用者事实。个人风格只从本人的真实修改提炼。
- AIHOT：可作发现资讯的渠道，但没有改成新闻唯一来源，也没有让远程返回的“回答提示”决定本地行为。技能文件许可与外部服务条款分别处理，不因MIT而默认获得数据商业使用权。
- Mac原生操控、豆包专用图标/视频、人物投资顾问等：不属于本轮本机任务；未安装、未配置账号或付费服务。
- 不自动联网更新、提交Git、回滚目录、批量改写规则或写长期记忆；具体外部动作仍依据当前任务授权。

## 与第一轮的关系

第一轮吸收报告数据口径、真实表达、变更后的相关文档同步与存储风险分类。来源分别是Huashu Report、Tramstop、neat-freak和storage-analyzer；Darwin启发小步比较方法，未安装优化器或采用分数自增作为质量证明。六篇本人X原帖已阅读，原帖提供方法背景，仓库固定版本提供实现与许可依据。

本轮新增一个有明确边界的工具调研技能；表格与答辩仍归课程交付，不拆成重复技能。论文精读、系统文献综述、PPT制作和绘图继续使用已有专门能力。

## 验证范围

旧版与候选版在两个独立上下文各执行3项请求，共6份输出，逐份读取确认均满足相应判据。用同一组离线虚构材料比较：工具资料冲突与兼容性、表格源数据、课堂答辩。执行产物在隔离目录，输入不修改，不安装或上传资料。判定依据是实际输出能否支持正确采用判断、发现数据问题并遵循提交要求，不以主观分数声称整体质量提升。

首轮候选未实际加载课程验收参考，复查加载后补充了源行定位和展示可读性，核心判定没有变化。根据这个观察，在入口增加明确的表格与答辩路由；另一独立实例从新入口找到相应章节并完成只读检查。独立检查未发现所查范围内的模板、权限或许可阻断问题。

已有迁移核验工具保持不变，16项单元测试通过。前一轮4组对照也全部通过。测试结果只说明这些场景的表现，不能推导为所有任务必然更好。
